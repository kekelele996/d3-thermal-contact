# 参考解说明

## 三个难点

| 编号 | 错误认知 | 正确知识 | 对应测试 |
|---|---|---|---|
| D1 | 铝块和样品贴紧，界面没有温降，热量按同一温度连续传入样品 | 界面存在接触热阻 R，块与样品表面之间按 `q = (T_block - T_s0) / R` 交换热量；R 与样品扩散时间常数在同一段温升曲线上重叠，必须与 α 联合反演 | `difficulty_1`（隐藏组 1，R 主导） |
| D2 | 样品背面与空气绝热，温升全部留在样品里 | 背面按 `-k dT/dx = h (T - T_amb)` 向环境散热；测试时间越长，忽略它把热扩散率压得越低 | `difficulty_2`（隐藏组 2，h 主导） |
| D3 | 加热功率是理想阶跃，从 t=0 起就是设定值 | 台架记录的是实测功率序列，爬升段有 15–25 s；只用终值当阶跃，会把早期温升算快，热扩散率被压低 | `difficulty_3`（隐藏组 3，功率爬升主导） |

三组隐藏运行各自让一个效应占主导，另外两个效应对应的参数取到可忽略：组 1 的 `h=0`，组 2 的 R 只有 5e-5–2.5e-4，组 3 的 R 只有 5e-6–3e-5。留一法跳过任一修复时，只有对应那一组失败。

## 关键步骤

1. 读 `meta.json`，把铝块折成单位面积热容 `C_b = 厚度 × 密度 × 比热容`，样品用 `ρc_p` 与热扩散率 α 表示，导热系数 `k = α ρc_p`。
2. 一维显式/隐式有限体积：块一个节点，样品 N 个节点；块与样品首节点之间串 R，样品末节点带对流边界。
3. 用实测功率序列插值到时间步上，按 Crank–Nicolson 推进。
4. 以 α 和 R 为未知量，对整条温升曲线做最小二乘。目标函数在两个参数上有狭长谷，单起点会掉进局部极小，因此从 6 个 R 起点分别优化，取残差最小者；当更小的 R 与最优残差之差在 4σ² 以内时，取小 R 的解（R 不可辨识时按理想接触报告）。
5. 输出 α 与 R，保留双精度，JSON 浮点。

## 核心公式与独立复算

- 控制方程：`ρc_p ∂T/∂t = k ∂²T/∂x²`，`0<x<L`；块：`C_b dT_b/dt = q(t) - (T_b - T(0,t))/R`；背面：`-k ∂T/∂x|_L = h (T(L,t)-T_amb)`。
- 长时极限：`dT_back/dt → q / (C_b + ρc_p L)`，与 R、α 无关，用来核对总热容。
- 界面温降：`T_b - T(0,t) → qR`，用来核对 R 的量级。
- 解析路径：Carslaw & Jaeger《Conduction of Heat in Solids》第 3 章的半无限体/有限厚板解，接触热阻按串联热阻处理；`research/derivations.md` 给了级数解的前几项与长时极限。
- 数值路径：`research/verify_forward.py` 用两种离散（隐式欧拉 dt=0.5/N=61 与 Crank–Nicolson dt=0.25/N=161）算同一组参数，端点温度差 < 0.001 K；再用独立的 `research/verify_inverse.py`（不同初值、不同网格）反演，α 差 < 0.2%。
- 两条路径与生成参数的差异：α < 0.3%，R < 1%（组 1）。最终容差取 α 1.5%、R 8%，均大于复算差异，小于典型错误解的偏差（见下）。

## 容差依据

- 正常抖动上限：温度噪声 0.02 K、采样 1 s，参考解在随机隐藏样本上的 α 误差 < 0.5%，R 误差 < 2%（组 1）。
- 典型错误解偏差：跳过 D1 时组 1 的 R 偏差约 −99%；跳过 D2 时组 2 的 α 偏差 −33% 以上；跳过 D3 时组 3 的 α 偏差 −27%。
- 取值理由：α 容差 1.5%（组 3）/2.5%（组 2），R 容差 8%（组 1），都留出 3 倍以上的余量，同时远小于错误解偏差。

## 数据来源

- 真实数据：无。样品证书与运行数据都是按本说明的模型生成的合成数据。
- 生成数据：`tests/refkit/cases.py`，参数范围见该文件的 `draw()`；温度噪声 0.02 K（固定标准差），功率记录叠加 0.4% 相对噪声；每次测试用 `secrets.randbits(63)` 取种子，种子写进检查记录。
- 复现命令：`python3 research/verify_forward.py`、`python3 research/verify_inverse.py`。
- 以上说明不在 `environment/` 内。
